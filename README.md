Лабораторная работа №1. Матрицы комплексных чисел

ОПИСАНИЕ

Программа для работы с матрицами комплексных чисел на языке Java. Реализованы классы Complex (комплексное число) и Matrix (матрица), а также консольный интерфейс для выполнения операций.

ВОЗМОЖНОСТИ
- Сложение матриц
- Вычитание матриц
- Умножение матриц
- Деление матриц (через обратную матрицу)
- Транспонирование
- Вычисление определителя

СТРУКТУРА ПРОЕКТА

Matrix_lab.java  — единый файл, содержащий три класса:
1. Matrix_lab (главный, с консольным меню)
2. Matrix (матрица)
3. Complex (комплексное число)

КЛАСС COMPLEX

Комплексное число вида a + bi. Хранит два поля:
- re — действительная часть
- im — мнимая часть

Методы:
- add(Complex) — сложение
- difference(Complex) — вычитание
- composition(Complex) — умножение
- division(Complex) — деление
- conjugation() — сопряжённое
- modul() — модуль
- getRe(), getIm() — геттеры
- output() — вывод

КЛАСС MATRIX

Матрица размера m × n из комплексных чисел. Внутри — массив Complex[][].

Методы:
- set(i, j, value) — установить элемент
- get(i, j) — получить элемент
- output() — вывод матрицы
- add(Matrix) — сложение
- difference(Matrix) — вычитание
- composition(Matrix) — умножение
- division(Matrix) — деление через обратную матрицу
- transpose() — транспонирование
- determinant() — определитель (рекурсия через миноры)

ИСПОЛЬЗОВАНИЕ 

После запуска появится меню:

Меню
1. Сложить матрицы
2. Вычесть матрицы
3. Умножить матрицы
4. Транспонировать матрицу
5. Определитель матрицы
6. Разделить матрицы
7. Выход

Выбор:

Введите номер операции, затем размеры матриц и их элементы. Каждый элемент вводится как пара чисел: re (действительная) и im (мнимая).

ДОПОЛНИТЕЛЬНЫЕ СВЕДЕНИЯ

В проекте применён принцип инкапсуляции: поля классов закрыты (private) и недоступны снаружи, а доступ к данным осуществляется только через публичные методы. 
В классе Complex поля re и im закрыты, чтение — через геттеры getRe() и getIm().
В классе Matrix поле matrix закрыто, доступ — через set(i, j, value) и get(i, j). Это защищает данные от случайного изменения извне и скрывает внутреннюю реализацию классов.
Также реализован безопасный ввод данных: все значения читаются через методы readInt() и readDouble() с обработкой исключений InputMismatchException — при вводе буквы вместо числа программа не падает, а просит повторить ввод.
Дополнительно реализованы проверки корректности: количество строк и столбцов должно быть больше нуля, размеры матриц при сложении, вычитании и делении должны совпадать, при умножении число столбцов первой матрицы должно равняться числу строк второй, а определитель и деление возможны только для квадратных матриц. При делении проверяется, что определитель делителя не равен нулю (иначе матрица вырожденная и обратной не существует).
Все ошибки сопровождаются понятными сообщениями, и программа возвращается в меню, не завершаясь аварийно.
